# 📝 Quiz App (Java Swing)

A desktop-based **Quiz Application** built using **Java Swing**. The app provides a clean GUI where users can enter their name, read quiz rules, and attempt questions in an interactive way.

---

## 🚀 Features

* User-friendly **Java Swing GUI**
* Login screen with name input
* Rules screen before starting the quiz
* Multiple-choice questions
* Image-based UI (icons support)
* Packaged as an executable **JAR** file

---

## 🛠️ Technologies Used

* **Java (JDK 17+)**
* **Java Swing & AWT**
* **Object-Oriented Programming (OOP)**

---

## 📂 Project Structure

```
src/
 └── quiz/
     └── app/
         ├── Login.java
         ├── Rules.java
         ├── Quiz.java
icons/
 └── login.png
QuizApp.jar
README.md
```

---

## ▶️ How to Run the Project

### Option 1: Run using JAR (Recommended)

1. Make sure **Java is installed** on your system
2. Double-click `QuizApp.jar`

   **OR** run via command line:

   ```bash
   javaw -jar QuizApp.jar
   ```

---

### Option 2: Run from Source Code

```bash
javac quiz/app/*.java
java quiz.app.Login
```
